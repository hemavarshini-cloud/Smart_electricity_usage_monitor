SMART ELECTRICITY USAGE MONITOR WEBSITE

1. Extract the ZIP file.
2. Open the folder in VS Code using File > Open Folder.
3. Open index.html in a browser, or right-click it in VS Code and select Open with Live Server.
4. Internet is required for Chart.js to load from its CDN.

This is a frontend prototype using illustrative sample data. It does not connect to a real smart meter. The bill estimate uses an assumed flat rate of ₹6.80/kWh; actual tariffs may differ.
